发现及修复：

- **中，功能/认证一致性**：`mcp/opencode.rs::convert_to_opencode_format` 丢弃导入时已保留的 `oauth`。导入后再同步会丢失显式禁用或自定义客户端配置。远程投影现在保留该字段，测试覆盖 `false`、对象、缺省值以及其余连接参数的完整往返。

- 维护性：修复沿用既有格式转换和草稿脱敏入口，不另建认证配置副本。
- **低，输入校验**：`claude_mcp::validate_command_in_path` 将目录路径误报为命令可用。现在与 PATH 搜索分支一致要求文件存在；这仍是文件检查，不执行命令，也不承诺文件内容可运行。

## 06 Skills 管理与存储

范围：Skills 页面及存储对话框、发现和变更 hook、IPC、安装/卸载/更新/导入、迁移、备份、仓库下载/解压/元数据解析、Skills DAO。追踪存储设置、云同步读写锁与各客户端原生目录的交互。

- **高，数据丢失**：破坏性操作使用忽略隐藏文件/字节码的更新哈希判断目录归属与完整性。只有 `.env` 不同的迁移目标会被当作相同，随后删除原目录；原生副本亦可能被覆盖。新增完整存储哈希，包含隐藏文件、空目录和链接本身，按类型和长度编码并流式读取；用于迁移、覆盖校验、导入和备份验证，保持更新缓存的既有语义。测试覆盖隐藏文件不同的副本和实际迁移的源目录保护。复制器跳过内部链接时，完整性校验现在会拒绝以不完整副本替代原件。
- **中，性能/资源耗尽**：元数据解析为了读取 YAML 头加载整个 `SKILL.md`，第三方大文档可消耗大量内存。改为流式读取最多 1 MiB 的头部，遇到结束分隔行即停止；测试覆盖大正文、正文非 UTF-8 和超长未闭合头部。
- **中，跨模块缓存一致性**：迁移提交后只更新对话框草稿和 Skills 查询，共享设置缓存仍指向旧根目录。现在刷新设置查询；通过独立订阅者确认其能读取新位置。
- 安全/恢复核查：压缩体与解压预算、路径穿越、符号链接物化预算、安装代次复核、分步提交补偿和迁移失败保留原目录已有防护；相关既有回归随本模块运行。完整目录比较增加隐藏文件读取成本，优先保证破坏性操作的完整性，未进行吞吐基准。

- **中，恢复一致性**：mode 恢复扫描后，逐文件发布前没有重新核对当前内容。补充发布前版本复核，跳过扫描后发生的外部编辑；注入扫描与发布间的编辑验证恢复结果和临时文件清理。
- **中，资源边界**：Codex 模型目录只查读取前的文件长度，文件增长时仍可能无界读取。改为对实际读取施加字节限额，再校验 UTF-8；缩小仅内部调用的读取辅助可见性，新增 Unicode 字节边界回归。
