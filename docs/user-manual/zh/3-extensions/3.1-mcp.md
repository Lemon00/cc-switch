# 3.1 MCP 服务器管理

MCP 用于让客户端连接外部工具和数据源。点击侧栏「MCP」打开全局面板：每行一个服务器，每列一个支持的应用，开关决定该应用是否启用它。

## 添加和编辑

1. 点击「添加 MCP」，选择模板或填写连接配置。
2. 可以粘贴 JSON / TOML；支持统一 `mcpServers`、Codex `[mcp_servers]` 和 OpenCode local / remote 格式。粘贴多个条目时逐项确认新增、跳过或覆盖。
3. 选择连接方式：本地命令（stdio）、HTTP 或 SSE。stdio 的程序与参数分别填写，远程地址必须使用 HTTP / HTTPS。
4. 在「写入到」中勾选目标应用，再保存。名称是原生配置的键，保存后不能直接改名。

环境变量、请求头、工作目录按需填写。显示名、标签和文档链接只用于 CC Switch。编辑现有配置时，JSON 中打码的敏感值会保留原值，不必重新输入。

各客户端支持的传输类型不同，例如 Antigravity 和 DeepSeek Harness 不支持 SSE。保存前的校验和导入结果会指出不兼容的条目。

## 支持的应用和默认路径

| 应用             | 配置位置                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Claude Code      | `~/.claude.json` 的 `mcpServers`                                                                                         |
| Codex            | `~/.codex/config.toml` 的 `[mcp_servers]`                                                                                |
| OpenCode         | `~/.config/opencode/opencode.json` 的 `mcp`                                                                              |
| DeepSeek Harness | `~/.dsh/profiles/<profile>/cordis.patch.yml`，具体 profile 规则见[接入说明](../../../deepseek-harness-integration-zh.md) |
| Antigravity      | `~/.gemini/config/mcp_config.json`                                                                                       |

共支持这 5 个受管应用。设置中的目录覆盖（Claude Code、Codex、OpenCode）和客户端自身环境变量（如 DeepSeek Harness 的 `DSH_HOME`）会改变实际路径。界面只显示「应用」页里可见的列，隐藏列不会关闭已经启用的服务器。

## 启用、关闭和删除

点单元格开关切换应用状态；列头和行菜单可批量操作，列操作只作用于当前筛选结果。失败应用会单独标出，可以重试。

写入会协调原生配置与数据库；原生写入或提交失败时尝试恢复之前的状态。多应用批量操作可能部分成功，应按反馈检查结果，不要假定所有客户端同时成功。

关闭和删除不同：

- Antigravity 关闭时写入 `disabled: true`，保留客户端本地选项。
- 其他应用按各自格式移除或禁用受管条目。删除会移除 CC Switch 档案及其负责的原生配置；未托管或无法确认归属的同名条目可能保留。

原生工具通常需要重新加载或重启才读取改动。不要把 CC Switch 保存成功等同于服务器已经启动或连通。

### 同步条件与冲突

部分客户端必须先有自己的配置目录，CC Switch 才写入 MCP（例如 Antigravity 需要 CLI 或定制目录存在）。请先启动客户端完成初始化，再核对页面显示的实际路径。

CC Switch 保留客户端的非传输选项，但编辑受管条目可能替换它的命令、地址等传输字段。遇到冲突应先核对外部修改，再重试。

## 从应用导入

点击「从应用导入」读取支持客户端的用户级配置。Claude Code 的项目级或插件 MCP 不在此范围。

同名服务器不会一概覆盖：配置相容时合并应用启用信息，冲突或无效条目会报告或跳过；原生禁用状态按适配器保留。查看导入结果中的读取失败和跳过原因，不能只看新增数量。

## 检查连通性

页头「检查连通性」检查已启用的服务器，行菜单「测试连接」只检查该行。打开页面本身不会自动启动服务器。检查执行 MCP 握手，配置变化后旧结果失效；stdio 进程会在检查结束、取消或超时后清理。

握手成功表示服务器可连接，不保证其所有业务工具可用。失败时检查程序是否安装、PATH、参数、网络和凭据；修改后重新检查。批量检查中可单独查看失败条目。

深链接导入格式见[深链接协议](../5-faq/5.3-deeplink.md)。
