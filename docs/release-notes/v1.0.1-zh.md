# CC Switch 1.0.1

预定版本，尚未发布。桌面应用、共享核心和 CLI 统一为 1.0.1，下载产物及发布时间以本仓库 Release 为准。

## 主要变化

- **Linux 轻量模式与同步性能**：直接轻量启动减少无用图形初始化；会话用量同步按实际文件批量读取历史游标，减少历史记录较多时的查询、复制与分配开销，保留 Codex 归档和压缩会话的进度继承。
- **路由与协议兼容**：修复切换供应商或路由模式后旧请求回写状态的问题；改进 Codex 工具调用、结果顺序、消息标识和流式协议转换，以及 Gemini 长历史处理。同步修正用量统计和去重边界。
- **配置与数据保护**：Skills 迁移完整比较隐藏文件、空目录和链接，避免不完整副本覆盖原件；改进备份恢复校验、MCP OAuth 同步与密钥遮蔽，以及配置写入失败后的补偿，保护外部程序在此期间修改的内容。
- **授权与资源边界**：限制 OAuth 回调、外部响应和 Skills 元数据读取；改进敏感日志过滤、异步取消与重复提交处理。
- **桌面与工具管理**：修复设置未保存提示、窗口状态更新、托盘导航和主题监听；改进工具安装来源识别、版本检查及进程清理，兼容 OpenCode 2.x 会话读取。
- **范围与清理**：继续管理 Claude Code、Codex、OpenCode、DeepSeek Harness、Antigravity 五个客户端。移除 Copilot/xAI 专用授权、额度、预设与路由代码，以及其他无调用代码和兼容转导出。

## 升级前留意

请备份 CC Switch 配置、Skills 和客户端原生文件。旧 Copilot/xAI 专用供应商会被跳过读取并拒绝重新保存；升级前请确认不再依赖这些入口。清理不会删除用户外部客户端目录、账号文件或历史备份。

从旧 4.x 版本迁移仍需手动安装独立版，版本重新编号不重置数据库 schema。避免两个版本同时修改同一套配置；回退时使用升级前备份。

## 性能验证

在 Linux Mint 22.3、WebKitGTK 2.52.6 的隔离 X11 环境，优化后的直接轻量启动约 **60.7 MiB PSS**，打开主界面后切入轻量约 **141.4 MiB PSS**。后者保留部分 WebKit 和图形运行时资源，不能等同于从未创建窗口的冷启动。

50000 条历史游标、700 个实际文件的合成负载中，连续 30 次同步耗时降低约 **82%–86%**；没有额外历史游标的小库存在约 **4.5–14 ms/次**开销回退。PSS 受共享库分摊影响，这些数据不代表所有平台或真实代理负载。测量使用更新版本号前的同一优化代码，详细方法、RSS、CPU 和适用范围见[性能报告](https://github.com/Lemon00/cc-switch/blob/v1.0.1/docs/performance-2026-11-28.md)。
