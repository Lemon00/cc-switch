# 1.4 简介与快速上手

CC Switch 独立版集中管理 **Claude Code、Codex、OpenCode、DeepSeek Harness 和 Antigravity** 五个 AI 编程客户端的配置、扩展与会话。本节介绍首次配置；完整功能列表见[项目首页](../../../../README.md)。

## 第一步：添加供应商

1. 在左侧栏选中要管理的工具，点击页面右上角的 **+**（添加供应商）
2. 在「预设供应商」中选择你的供应商
   - 常用预设：智谱 GLM、MiniMax、DeepSeek、Kimi、PackyCode 等
   - 或选择「自定义配置」手动配置
3. 填写 **API Key**
4. 点击「添加」

> 💡 **提示**：添加面板支持按中文名和域名搜索，同一家的不同套餐和地区合并成一行。预设会自动填充端点地址，你只需要填写 API Key。

## 第二步：切换供应商

添加完成后，供应商会出现在列表中。

**方式一：应用页切换 / 添加**

- **Claude Code / Codex**：点击供应商卡片的「切换」按钮，状态会显示为「使用中」
- **OpenCode / DeepSeek Harness**：属于共存式应用，按钮为「添加 / 移除」，可以同时添加多个供应商
- **Antigravity**：官方登录卡改写本机默认模型；第三方 Key 卡通过卡片上的「打开终端」使用独立隔离目录启动 `agy`

**方式二：托盘快速切换**

- 点击系统托盘图标打开快捷面板，或在原生菜单中右键系统托盘图标
- **Claude Code** 和 **Codex** 支持在托盘直接切换当前供应商或查看额度摘要

## 第三步：生效方式

切换或添加供应商后，各客户端的生效方式不同：

| 应用             | 生效方式                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| Claude Code      | ✅ 即时生效（支持热重载）                                                                         |
| Codex            | 需要关闭并重新打开终端 / 彻底重启 Codex 桌面版                                                    |
| OpenCode         | 需要关闭并重新打开终端，并在 OpenCode 中选择模型                                                  |
| DeepSeek Harness | 写入对应 profile 配置；运行 `dsh web` 或重启客户端后在模型选择器中选择                            |
| Antigravity      | 官方卡切换后新开的 `agy` 会话生效；第三方 Key 卡点击「打开终端」在隔离进程中立即生效              |

处于路由模式时，Claude Code 和 Codex 切换路由目标会立即作用于后续请求；但如果切换改变了模型目录，Codex 仍需要彻底重启。

## 直连、路由和聚合（可选）

**Claude Code** 和 **Codex** 的页面顶部有「直连 / 路由 / 聚合」标签。点标签只是切换查看的内容，不会改动配置；真正切换要点页面上写明后果的按钮：「开始路由」、「切换到聚合模式」，回到直连点「回到直连」。

- **直连**（默认）：客户端直接连供应商，日常使用选它
- **路由**：请求经本机 CC Switch 转发（默认 `127.0.0.1:15721`），可以转换接口格式、做故障转移。想在 Claude Code 里用 OpenAI 或 Gemini 格式的供应商，或在 Codex 里用 Claude 或 Chat Completions 格式的供应商，选它
- **聚合**：把多家供应商的模型放进同一个模型列表，选哪个模型请求就发给哪一家，公共模型支持自动轮询与故障转移

路由和聚合需要 CC Switch 保持运行；退出 CC Switch 会自动回到直连，下次启动再接上。官方订阅默认不经过路由（Codex 的 OpenAI Official 例外）。详见 [开启本地路由](../4-proxy/4.1-service.md)。

### Claude Code 首次安装提示

如果 Claude Code 首次启动时提示需要**登录**或显示初始化引导，请在 CC Switch 中开启「跳过 Claude Code 初次安装确认」选项：

1. 打开 CC Switch「设置 → 应用配置 → Claude Code」
2. 开启「跳过 Claude Code 初次安装确认」开关
3. 重新启动 Claude Code

> ⚠️ **注意**：此选项会在 `~/.claude.json` 中写入 `hasCompletedOnboarding: true`，跳过官方的初次安装确认流程。

## 验证配置

配置完成后，启动对应的 CLI 工具并输入简单的问题进行测试：

```bash
# Claude Code - 启动后输入测试问题
claude
> 你好，请简单介绍一下自己

# Codex - 启动后输入测试问题
codex
> 你好，请简单介绍一下自己

# OpenCode - 启动后输入测试问题
opencode
> 你好，请简单介绍一下自己

# DeepSeek Harness - 启动 Web 界面
dsh web

# Antigravity - 官方卡直接运行；第三方 Key 卡请点击卡片上的「打开终端」
agy
```

如果 AI 能正常回复，说明配置成功。

> **注意**：首次启动时，CC Switch 会自动导入 Claude Code、Codex、OpenCode 的现有配置（Antigravity 在自带模型配置存在时导入），并为 Claude Code / Codex 添加官方供应商，原有配置不会丢失。

## 常见问题

### 切换后不生效？

确保重启了终端或 CLI 工具（Claude Code 除外，支持热重载）。配置文件在切换时已经更新，但运行中的程序一般不会自动重新加载。

### 找不到预设？

如果你的供应商不在预设列表中，选择「自定义配置」手动配置。参考 [添加供应商](../2-providers/2.1-add.md) 了解配置格式。

### 如何恢复官方登录？

Claude Code、Codex 和 Antigravity 均支持官方登录（如 Claude Official、OpenAI Official、Antigravity 官方登录卡）；如果列表里没有，可以从预设里重新添加后切换并按工具自身的登录流程操作。
