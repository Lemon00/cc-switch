# 2.3 编辑与管理供应商

## 打开编辑面板

1. 找到要编辑的供应商卡片
2. 点击卡片右侧的铅笔图标（「编辑」）
3. 进入整页编辑器；点「返回供应商列表」离开

## 可编辑内容

### 基本信息

| 字段     | 说明                                 |
| -------- | ------------------------------------ |
| 名称     | 供应商显示名称                       |
| 备注     | 附加说明信息                         |
| 网站链接 | 供应商官网或控制台地址               |
| 图标     | 内置图标，或「我的图标」里上传的图片 |

### 图标自定义

点名称左边的图标打开图标选择器，点一个图标就选好并关闭。选择器分两组，上面的搜索框同时筛两组：

- **我的图标**：自己上传的图片。点第一格「上传」选一张 PNG、JPG、WebP 或 SVG（不超过 2 MB），起个名字后存进「我的图标」并用在当前供应商上；以后其他供应商、其他应用也能直接选，不用再传一次。鼠标移到图标上可以重命名或删除，删除只是从「我的图标」里拿掉，已经在用它的供应商不受影响。
- **内置图标**：常见 AI 服务商和工具的图标。

图片会缩成 96×96 的 PNG，「我的图标」和供应商配置随云同步一起带走，不在磁盘上另存文件。通过一键导入链接带来的网站图标，会以「当前图标」显示在「我的图标」里，可以存进去给其他供应商用。要去掉图标，点搜索框旁的「清除图标」，卡片退回名称首字母。

### 配置信息

表单里的 API Key、端点地址、模型等，以及面板底部的配置编辑框，见下方 [配置编辑框](#配置编辑框)。

## 配置编辑框

**Claude Code** 和 **Codex** 的编辑面板底部，显示的是**切到这个供应商之后，工具配置文件的样子**：

| 应用        | 编辑框                                                                    |
| ----------- | ------------------------------------------------------------------------- |
| Claude Code | `~/.claude/settings.json`                                                 |
| Codex       | `~/.codex/config.toml`（Key 在上方的 API Key 输入框里，不在编辑框中重复） |

编辑框里的内容分两类，编辑框上方有一行说明列出这个应用的第一类包括哪些：

- **随供应商切换的**：请求地址、Key、模型名、接口协议等关键字段，以及少数跟着供应商走的兼容选项（如上下文窗口）。显示的是这个供应商自己的值，保存后存进这个供应商。
- **全局设置**：其余所有内容，比如插件、Hook、权限、MCP、你自己加的环境变量。显示的是工具配置文件里现在的内容，保存后直接写进配置文件，对所有供应商生效。

编辑当前供应商和编辑其他供应商，规则完全一样：不管编辑哪个供应商，改全局设置都会立即写进配置文件。处于路由模式时，编辑框里的关键字段显示的也是供应商自己的真实地址和 Key，不是本地路由地址。

### 在工具里改的设置

- **全局设置**：在工具里改了（比如装了插件），打开编辑面板就能看到，切换供应商也不会改动它们。
- **关键字段**：在工具里临时换的模型（比如 Claude Code 的 `/model`）不会存回供应商，切走再切回来会恢复成供应商保存的值。想长期修改，请在这里编辑供应商。

> 💡 **通用配置片段已冻结**：旧版本有「通用配置片段」，切换时合并进配置文件，编辑当前供应商时还会把配置文件整份读回供应商（「回填」）。新版本两者都不再做：共享设置本来就留在配置文件里，不需要存进某一个供应商，也不需要片段。已有供应商里留着的片段只给旧版本读取，不影响新版本。

### 编辑期间配置文件被改过

保存时，CC Switch 只提交你在编辑框里改过的设置，并逐条检查：打开编辑面板之后，这条设置在配置文件里有没有被工具或其他程序改过。

- 没被改过：直接写入。
- 被改过：弹出「配置文件在编辑期间被修改」，列出这些设置，由你选择「保留外部修改」或「用我的修改覆盖」。其余改动照常保存。

你没改过的设置不会提交，所以不会覆盖工具在这期间写入的内容。

### 不随切换生效的设置

旧版本的「回填」、深链导入或旧预设，可能让供应商里存着一些关键字段以外的设置。这些设置不会写进配置文件，编辑框下方会把它们列出来：

- **Claude Code**：点击某一项，把它加入上方编辑框，保存后作为全局设置写进配置文件。
- **Codex**：点击某一项复制它的 TOML，按需粘贴到上方编辑框。

供应商里保存的原值不会删除。

### 配置文件读不出来时

如果工具的配置文件格式有错误，编辑框会改为显示供应商里保存的内容，并在上方提示原因。修好配置文件后重新打开编辑面板即可。

## 自动获取模型

编辑供应商时，可以自动从供应商端点获取可用模型列表：

1. 确保已填写 API Key 和端点地址
2. 点击模型输入框旁的 **获取模型** 按钮（下载图标）
3. 从分组下拉菜单中选择模型

详细说明请参阅 [2.1 添加供应商 — 自动获取模型](./2.1-add.md#自动获取模型)。

## 快捷开关（Claude）

编辑 Claude 供应商时，JSON 编辑器上方提供常用设置的快捷开关，包括工具搜索、禁用自动更新、Teammates、最大强度思考等。其中「启用 Tool Search」和「禁用 Artifact 工具」跟随供应商，其余是全局设置。详见 [2.1 添加供应商 — Claude 快捷开关](./2.1-add.md#claude-快捷开关)。

## 修改 API Key

编辑供应商时，可以直接在 **API Key** 输入框中修改：

1. 点击供应商卡片的「编辑」按钮
2. 在「API Key」输入框中输入新的密钥
3. 点击「保存」

> 💡 **提示**：API Key 输入框支持显示/隐藏切换，点击右侧的眼睛图标可查看完整密钥。

## 修改端点地址

编辑供应商时，可以直接在 **端点地址** 输入框中修改：

1. 点击供应商卡片的「编辑」按钮
2. 在「端点地址」输入框中输入新的 URL
3. 点击「保存」

### 端点地址格式

| 应用        | 格式示例                     |
| ----------- | ---------------------------- |
| Claude      | `https://api.example.com`    |
| Codex       | `https://api.example.com/v1` |
| Antigravity | `https://api.example.com`    |

## 添加自定义端点

供应商可以配置多个端点，用于：

- 速度测试时测试多个地址
- 故障转移时的备用端点

### 自动收集

添加供应商时，CC Switch 会自动从配置中提取端点地址。

### 手动添加

编辑供应商时，在「端点管理」区域可以：

- 添加新端点
- 删除现有端点
- 设置默认端点

## JSON / TOML 编辑器

Claude Code、OpenCode、Antigravity 的配置编辑框使用 JSON，Codex 使用 TOML，DeepSeek Harness 使用 YAML / 结构化配置。编辑器提供：

- 语法高亮
- 格式校验
- 错误提示

### 常见错误（以 JSON 为例）

**缺少引号**：

```json
// ❌ 错误
{ env: { KEY: "value" } }

// ✅ 正确
{ "env": { "KEY": "value" } }
```

**多余逗号**：

```json
// ❌ 错误
{ "env": { "KEY": "value", } }

// ✅ 正确
{ "env": { "KEY": "value" } }
```

**未闭合括号**：

```json
// ❌ 错误
{ "env": { "KEY": "value" }

// ✅ 正确
{ "env": { "KEY": "value" } }
```

## 保存与生效

1. 点击页面底部的「保存」按钮
2. 如果表单检测到非阻塞问题，会出现「配置存在以下问题」确认提示，点「仍要保存」后仍可保存
3. 全局设置的改动立即写入配置文件，不管编辑的是不是当前供应商
4. 关键字段的改动存进供应商。直连模式下，如果编辑的是正在使用的供应商，同时写入配置文件；路由模式下，如果编辑的是路由正在使用的供应商，而且改动影响路由写进配置文件的内容（比如模型名），配置文件也会一并更新
5. 是否需要重启工具，和切换供应商相同，见 [2.2 切换供应商](./2.2-switch.md)

## 取消编辑

点击「取消」或「返回供应商列表」离开编辑页，修改不会保存；有未改完的内容时会提示「有未保存的修改」，选「放弃修改并离开」才会丢弃。

## 拖拽排序

通过拖拽调整供应商的显示顺序。

### 操作步骤

1. 将鼠标移到供应商卡片上，卡片最左侧会出现 **⋮⋮** 拖拽手柄（平时隐藏）
2. 按住鼠标左键
3. 上下拖动到目标位置
4. 松开鼠标完成排序，会提示「排序已更新」

### 排序用途

- **常用优先**：将常用的供应商放在列表顶部
- **故障转移顺序**：队列里的顺序就是供应商的排序。在「路由」标签的「队列 · 按优先级」里，也可以点卡片上的上移、下移按钮，或直接拖动，调整先发给谁；详见 [4.3 故障转移](../4-proxy/4.3-failover.md)
- 托盘菜单里的供应商顺序也跟着变

## 复制供应商

快速创建供应商的副本，适用于：

- 基于现有配置创建变体
- 备份当前配置
- 创建测试用配置

统一供应商列表（添加页里「统一供应商」分类下的「管理已有的统一供应商」）也提供复制按钮，可直接从现有统一供应商创建副本后再调整同步应用和模型。

### 操作步骤

1. 点击供应商卡片右侧的 **⋯**（更多）按钮
2. 选择「复制」
3. 自动创建副本，名称后缀 `copy`
4. 点卡片上的编辑按钮，修改副本的配置

### 复制内容

复制会创建一个副本，带上：

| 内容     | 是否复制                            |
| -------- | ----------------------------------- |
| 名称     | ✅ 复制（添加 `copy` 后缀）         |
| 配置     | ✅ 完整复制                         |
| 备注     | ❌ 不复制，需要的话在副本里重新填写 |
| 网站链接 | ✅ 复制                             |
| 图标     | ✅ 复制                             |
| 端点列表 | ✅ 复制                             |
| 排序位置 | ✅ 排在原供应商之后                 |

### 复制后编辑

复制完成后，通常需要修改：

1. **名称**：改为有意义的名称
2. **API Key**：如果是不同账号
3. **端点**：如果是不同服务

## 删除供应商

### 操作步骤

1. 点击供应商卡片右侧的 **⋯**（更多）按钮
2. 选择「删除」（红色，在菜单最下面）
3. 在确认框里确认删除

### 删除确认

删除前会弹出确认对话框，显示：

- 供应商名称
- “此操作无法撤销”的提示

### 删除限制

- **正在使用的供应商**：不能删除，「删除」是灰的，说明里写着「正在用的这家不能删除，先切到别家」。切换式应用里，直连用的那家、路由或聚合模式下正在路由的那家都算；先切到别家再删
- **统一供应商**：删除后，关联的应用配置也会被删除
