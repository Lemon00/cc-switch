# CC Switch 1.0.0

这是 `Lemon00/cc-switch` 独立维护后的首个版本，版本号从 1.0.0 重新开始。项目基于 CC Switch 的既有实现继续发展，保留上游版权与 MIT 许可。仓库仅维护独立版本的发布记录。

本文介绍独立版 1.0.0 的功能与迁移方式。下载文件及发布时间以本仓库 Release 为准。

## 这个版本可以做什么

- **管理 5 个客户端**：Claude Code、Codex、OpenCode、DeepSeek Harness 和 Antigravity。按客户端能力提供供应商切换、多供应商共存或独立终端接入，以及原生配置编辑与工具管理。旧版数据库中的其他应用记录和原生配置保留兼容读取，不再暴露应用入口或自动扫描。
- **本地路由与聚合**：为 **Claude Code** 和 **Codex** 提供协议适配、模型映射、故障转移（含聚合公共模型轮询）和聚合模型目录，并支持局域网访问令牌与客户端连接地址配置。
- **扩展管理**：集中管理 MCP、Skills 和提示词，支持 5 个受管应用的按需同步、MCP 连通性检查与 Skills 仓库及存储管理。
- **会话、用量和账号**：浏览与搜索 5 个受管客户端的会话（支持删除 Claude Code、Codex、OpenCode 及 Antigravity CLI 会话），查看 Token 和费用统计，管理价格、汇率及供应商用量查询；授权中心管理 Claude 官方账号、GitHub Copilot、ChatGPT（Codex OAuth）、xAI、DeepSeek Harness 账号及 macOS 上的 Antigravity 官方账号。
- **桌面与数据管理**：托盘菜单与快捷面板、轻量模式、深链接导入、设备设置、备份恢复和 WebDAV / S3 同步。
- **独立 CLI 与 TUI**：与桌面复用 `cc-switch-core`，默认支持 Codex 与 Antigravity（可通过 `frontend-apps.json` 配置白名单），提供 `cc-switch-cli tui` 交互编辑供应商与 CLI 设置。

各客户端能力不同，完整说明见[用户手册](https://github.com/Lemon00/cc-switch/blob/v1.0.0/docs/user-manual/zh/README.md)及[五应用范围更新](https://github.com/Lemon00/cc-switch/blob/v1.0.0/docs/release-notes/five-apps-2026-11-26.md)。

## 本轮稳定性改进

- **托盘和窗口**：处理连续刷新中的过期结果，面板隐藏后停止主动刷新与用量轮询；读取失败时保留已有内容并提供重试。窗口重建与轻量模式共用生命周期协调，轻量偏好会保存。
- **深链接导入**：限制 URL、参数数量及解码内容大小，拒绝重复参数和无效类型；合并配置后再次检查地址。确认框防止重复提交，写入成功后的刷新失败会单独提示，避免重复导入。
- **异步数据与缓存**：供应商快照查询和原生配置刷新分开；恢复、导入及应用切换时处理旧请求、事件订阅和缓存失效，减少过期数据回写。
- **配置与持久化**：统一部分配置写入锁和 MCP 提交顺序，补充文件与数据库写入失败的补偿；导入、恢复、Skills 和原生配置操作加强冲突及边界检查。跨文件和数据库仍不构成一个原子事务。
- **文档**：按当前实现重整安装、设置、扩展和深链接手册，集中维护架构、测试入口和模块划分，移除重复审查报告与过时操作说明。

## 从旧版本迁移

1. 在旧版「设置 → 数据」导出配置，并备份实际配置目录。Skills 文件和客户端原生文件需按[配置文件说明](https://github.com/Lemon00/cc-switch/blob/v1.0.0/docs/user-manual/zh/5-faq/5.1-config-files.md)分别保留。
2. 退出旧版，从本仓库的 Release 手动安装独立版。1.0.0 小于旧版 4.x，旧版自动更新不会把它识别为更高版本；Windows 若阻止安装较低版本，先卸载旧应用，再安装 1.0.0，保留配置目录。
3. 新版继续使用现有配置路径和数据库迁移机制。启动后核对供应商、原生目录及路由状态；不要同时运行两个版本修改同一套配置。

版本重新编号不会重置数据库 schema，也不代表旧程序能够读取新版数据库。需要回退时使用升级前的备份。

## 下载与验证范围

本仓库发布工作流配置的产物为 Windows x64 MSI / 便携 ZIP、Linux x64 deb / GUI 压缩包及 Linux CLI。macOS、ARM64、RPM 和 AppImage 不属于当前发布矩阵，需要自行构建；不要把上游下载渠道当作独立版下载入口。

应用内更新从本仓库读取清单，需要发布时配置签名密钥。没有签名产物时使用手动下载。更新内容摘要及详细说明均指向本仓库。

测试方法和现有回归入口见[测试指南](https://github.com/Lemon00/cc-switch/blob/v1.0.0/docs/testing.md)。单元测试覆盖不能代替真实托盘、窗口焦点、自启及安装包的桌面验收；本文不宣称已完成这些实机验证。
