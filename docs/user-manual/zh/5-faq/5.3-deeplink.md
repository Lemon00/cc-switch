# 5.3 深度链接协议

## 功能说明

CC Switch 支持 `ccswitch://` 深度链接协议，可以通过链接一键导入配置。

**使用场景**：

- 团队共享配置
- 教程中的一键配置
- 跨设备快速同步

## 生成链接

按下面的资源格式构造 URL，参数值使用 URL 编码；内联配置按对应要求先做 Base64 编码。独立版不提供随仓库维护的在线生成站点，包含凭据的链接请直接在可信环境生成。

## 协议格式

### V1 协议

使用 URL 参数格式，易读易生成：

```
ccswitch://v1/import?resource={type}&app={app}&name={name}&...
```

链接按 UTF-8 字节计最多 256 KiB、64 个参数，解码后的同名参数不能重复；Base64 字段本身也受 256 KiB 上限约束。布尔值只接受 `true` / `false`，自动查询间隔必须为非负整数；链接不接受用户名、密码、端口或片段（`#...`）。配置合并失败时，确认框会显示原因并禁用导入按钮。

**通用参数**：

| 参数       | 必填                  | 说明                                                                                                                  |
| ---------- | --------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `resource` | 是                    | 资源类型：`provider` / `mcp` / `prompt` / `skill`                                                                     |
| `app`      | 是                    | 应用类型（provider、prompt 需要）：`claude` / `codex` / `opencode` / `agy`。DeepSeek Harness（`dsh`）供应商、提示词暂不支持深链接导入 |
| `name`     | provider、prompt 必填 | 名称（MCP 的服务器 ID 取自 `config` 中 `mcpServers` 的 key；Skill 不需要）                                            |

**供应商参数**（resource=provider）：

| 参数                | 必填 | 说明                                                                                                                                                                                                                                                                                                                                   |
| ------------------- | ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `endpoint`          | 否   | API 端点地址（支持逗号分隔多个 URL）                                                                                                                                                                                                                                                                                                   |
| `apiKey`            | 否   | API 密钥                                                                                                                                                                                                                                                                                                                               |
| `homepage`          | 否   | 供应商官网                                                                                                                                                                                                                                                                                                                             |
| `model`             | 否   | 默认模型。Claude Code 用原版 Claude 模型时可留空                                                                                                                                                                                                                                                                                       |
| `apiFormat`         | 否   | 接口格式：`anthropic` / `openai_chat` / `openai_responses` / `gemini_native`，按应用换算（OpenCode 的 `npm`；Claude Code、Codex 写非原生格式时需开启本地路由；Antigravity 仅支持 `gemini_native`）。不写用应用的默认格式；应用不支持的格式会被拒绝                                                                                           |
| `haikuModel`        | 否   | Haiku 模型（仅 Claude）                                                                                                                                                                                                                                                                                                               |
| `sonnetModel`       | 否   | Sonnet 模型（仅 Claude）                                                                                                                                                                                                                                                                                                              |
| `opusModel`         | 否   | Opus 模型（仅 Claude）                                                                                                                                                                                                                                                                                                                |
| `notes`             | 否   | 备注                                                                                                                                                                                                                                                                                                                                   |
| `icon`              | 否   | CC Switch 内置图标名，只能是小写字母、数字和 `. _ -`，其他写法会被丢掉                                                                                                                                                                                                                                                                 |
| `iconUrl`           | 否   | 自己的图标图片地址。确认框打开时下载，导入后作为卡片图标；必须是 https、域名、默认端口，公开可访问，不超过 256 KB，`Content-Type` 为 PNG / JPEG / WebP / SVG 且与文件一致。下载失败时退回 `icon` 或名称首字母，不报错                                                                                                                  |
| `config`            | 否   | Base64 编码的配置内容。Codex 写成 `{"auth": {...}, "config": "<config.toml 文本>"}`，或用 `configFormat=toml` 直接给整份 config.toml；只导入选中的 `[model_providers.*]` 表里的连接和鉴权字段（如 `wire_api`、`http_headers`、`supports_websockets`、与地址同源的 `model_catalog_url`）以及顶层的模型、推理强度、`web_search` 等，选路统一改成 `custom`；`[features]`、MCP、权限等全局设置不导入；表里带 `auth`、`aws`、`gateway_oauth`、`env_http_headers` 的链接会被拒绝，`env_key` 会被忽略（Key 用链接给的） |
| `configFormat`      | 否   | 配置格式：`json` / `toml`                                                                                                                                                                                                                                                                                                              |
| `configUrl`         | 否   | 暂不支持，带了会被拒绝；请改用 `config` 内联                                                                                                                                                                                                                                                                                           |
| `enabled`           | 否   | 确认框里「导入后立即切换」开关的初始值（OpenCode 是「添加到应用配置」，不写时默认打开），导入时以开关为准                                                                                                                                                                                                                              |
| `usageScript`       | 否   | 用量查询脚本                                                                                                                                                                                                                                                                                                                           |
| `usageEnabled`      | 否   | 是否启用用量查询。未传时：带了 `usageScript` 就启用，否则不启用；传 `false` 则只导入不启用，可在应用内手动开启。脚本正文会完整展示在导入确认框中                                                                                                                                                                                       |
| `usageApiKey`       | 否   | 用量查询专用 API Key                                                                                                                                                                                                                                                                                                                   |
| `usageBaseUrl`      | 否   | 用量查询专用地址                                                                                                                                                                                                                                                                                                                       |
| `usageAccessToken`  | 否   | 用量查询访问令牌                                                                                                                                                                                                                                                                                                                       |
| `usageUserId`       | 否   | 用量查询用户 ID                                                                                                                                                                                                                                                                                                                        |
| `usageAutoInterval` | 否   | 自动查询间隔（分钟）                                                                                                                                                                                                                                                                                                                   |

**提示词参数**（resource=prompt）：

| 参数          | 必填 | 说明                                                     |
| ------------- | ---- | -------------------------------------------------------- |
| `content`     | 是   | 提示词内容，须 Base64 编码（再做 URL 转义）              |
| `description` | 否   | 描述                                                     |
| `enabled`     | 否   | 确认框里「导入后立即启用」开关的初始值，导入时以开关为准 |

**MCP 参数**（resource=mcp）：

| 参数      | 必填 | 说明                                                                                                                    |
| --------- | ---- | ----------------------------------------------------------------------------------------------------------------------- |
| `apps`    | 是   | 应用列表（逗号分隔，如 `claude,codex,opencode`）。可用值：`claude` / `codex` / `opencode` / `dsh` / `agy`               |
| `config`  | 是   | MCP 配置 JSON，格式为 `{"mcpServers": {"<服务器 ID>": {...}}}`，须 Base64 编码（再做 URL 转义）                         |
| `enabled` | 否   | 暂不生效                                                                                                                |

**Skill 参数**（resource=skill）：深链接添加的是 Skill 仓库，不会直接安装 Skill；添加后到「Skills」页选择要安装的 Skill。

| 参数        | 必填 | 说明                                            |
| ----------- | ---- | ----------------------------------------------- |
| `repo`      | 是   | 仓库（格式：`owner/name`）                      |
| `directory` | 否   | 当前仓库导入不使用该字段，不会据此安装单个技能  |
| `branch`    | 否   | Git 分支，默认 `main`                           |
| `enabled`   | 否   | 是否启用这个仓库，默认 `true`；不是技能安装开关 |

**示例**：

```
ccswitch://v1/import?resource=provider&app=claude&name=My%20Provider&endpoint=https%3A%2F%2Fapi.example.com&apiKey=sk-xxx
```

## 导入类型示例

### 导入供应商

```
ccswitch://v1/import?resource=provider&app=claude&name=My%20Provider&endpoint=https%3A%2F%2Fapi.example.com&apiKey=sk-xxx
```

### 导入 MCP 服务器

```
ccswitch://v1/import?resource=mcp&apps=claude,codex&config=eyJtY3BTZXJ2ZXJzIjp7Im1jcC1mZXRjaCI6eyJjb21tYW5kIjoidXZ4IiwiYXJncyI6WyJtY3Atc2VydmVyLWZldGNoIl19fX0%3D
```

其中 `config` 是 `{"mcpServers":{"mcp-fetch":{"command":"uvx","args":["mcp-server-fetch"]}}}` 的 Base64 编码（末尾的 `=` 转义为 `%3D`）。

### 导入 Prompt 预设

```
ccswitch://v1/import?resource=prompt&app=claude&name=%E4%BB%A3%E7%A0%81%E5%AE%A1%E6%9F%A5&content=IyDop5LoibIK5L2g5piv5LiA5Liq5LiT5Lia55qE5Luj56CB5a6h5p%2Bl5LiT5a62
```

其中 `content` 是提示词 `# 角色\n你是一个专业的代码审查专家` 的 Base64 编码（`+` 转义为 `%2B`）。

### 导入 Skill

```
ccswitch://v1/import?resource=skill&repo=owner/repo&directory=skills/my-skill&branch=main
```

## 生成深度链接

### 手动生成

1. 准备参数
2. 按 V1 协议格式拼接 URL
3. URL 编码特殊字符

**示例**：

```javascript
const params = new URLSearchParams({
  resource: "provider",
  app: "claude",
  name: "My Provider",
  endpoint: "https://api.example.com",
  apiKey: "sk-xxx",
});

const url = `ccswitch://v1/import?${params.toString()}`;
```

## 导入结果与错误处理

- `endpoint`、`homepage` 和 `usageBaseUrl` 只接受 HTTP(S) URL；从内联配置补齐的值也会校验。
- 确认框合并配置失败时显示错误并禁止提交。一次提交未结束前不能重复点击导入。
- 写入完成但界面刷新失败时会提示“导入已完成”，请重新打开页面，不要再次导入同一链接。
- MCP 的 `mcpServers` 必须是非空对象。相同服务器 ID 已存在时保留已保存定义、合并应用开关；批量导入会报告成功与失败数量。
- 链接可能包含 API Key 或其他凭据，只向预期接收者分享。

## 使用深度链接

### 点击链接

在浏览器或其他应用中点击深度链接：

1. 系统会询问是否打开 CC Switch
2. 确认后 CC Switch 打开
3. 显示导入确认对话框
4. 确认导入

### 导入确认

导入前会显示确认对话框，包含：

- 导入类型
- 配置预览
- 确认/取消按钮

确认后的效果因类型而异：供应商出现在对应应用的供应商列表里，是否立即切换（OpenCode 是是否写进应用配置）由确认框里的开关决定；MCP 会立即写入所有指定应用的配置文件；提示词是否立即启用也由确认框里的开关决定，启用后同一应用里其他提示词被禁用。若配置中带有可疑内容（指向本机或内网的地址、可改变进程加载行为的环境变量、通过 shell 执行整段命令、用量查询脚本等），对话框会给出风险提示，请逐项核对。

**安全提示**：只导入来自可信来源的配置。

## 协议注册

### 自动注册

CC Switch 安装时会自动注册 `ccswitch://` 协议。

### 手动注册

如果协议未正确注册：

**macOS**：
重新安装应用（把 CC Switch 放进「应用程序」文件夹后至少打开一次）。

**Windows**：
重新安装应用，或检查注册表：

```
HKEY_CLASSES_ROOT\ccswitch
```

**Linux**：
检查 `.desktop` 文件中的 `MimeType` 配置。

## 安全考虑

### 敏感信息

深度链接中可能包含敏感信息（如 API Key）：

- 不要在公开场合分享包含 API Key 的链接
- 分享前移除或替换敏感信息
- 使用安全渠道传输链接

### 验证来源

导入前 CC Switch 会：

1. 验证数据格式
2. 显示配置预览
3. 要求用户确认

### 恶意链接防护

CC Switch 会检查：

- 数据格式是否合法
- 必填字段是否完整
- 配置值是否在合理范围

## 故障排除

### 链接无法打开

**检查**：

1. CC Switch 是否已安装
2. 协议是否正确注册
3. 链接格式是否正确

### 导入失败

**可能原因**：

- Base64 编码错误
- JSON 格式错误
- 缺少必填字段

**解决方法**：

1. 检查原始 JSON 格式
2. 重新进行 Base64 编码
3. 确保所有必填字段都存在
