# CLI 交互管理（TUI）

在交互式终端启动：

```bash
cc-switch-cli tui
cc-switch-cli --app codex tui
cc-switch-cli --app agy tui
```

从源码运行：

```bash
cargo run --locked --manifest-path crates/cc-switch-cli/Cargo.toml -- tui
```

TUI 与 CLI、桌面端共用核心服务、配置目录和数据库，遵循 `CC_SWITCH_CONFIG_DIR` 及桌面端自定义目录。应用范围沿用 `frontend-apps.json` 的 `cli` 白名单，默认 Codex、Antigravity。不带命令仍显示 CLI 帮助。

## 界面与导航

顶部显示应用和当前供应商，左侧菜单切换模块，内容区显示当前页面的操作。配色参考 `cc-switch-cli` 的 Dracula 风格，支持 `COLORFGBG` 浅色终端以及 `NO_COLOR`。不依赖 Nerd Font。

- `Tab` / `←` / `→` 在菜单与内容间切换；菜单中 `↑↓` 后 `Enter` 打开页面。
- `1`–`9` 直接打开对应模块；`[` / `]` 切换应用。
- `↑↓` / `j k` 选择项目，`Home` / `End` 跳到首尾，`PageUp` / `PageDown` 移动十项。
- `/` 搜索名称或 ID，`Enter` 保留搜索，`Esc` 清除。
- `?` / `F1` 打开当前页面的帮助，支持滚动；`F4` / `!` 查看完整操作结果。
- `q` / `Ctrl+C` 退出。编辑器内字符作为输入，使用 `Esc` 返回。

窗口不足 88 列时菜单与内容分屏显示，仍使用 `Tab` 切换。最小支持 48 列 × 12 行，建议 100 列 × 28 行以上。快捷键放不下时显示 `? 更多`。

## 功能

| 模块 | 操作 |
| --- | --- |
| 首页 | 当前供应商、提示词、MCP / 技能数量、配置位置、代理状态 |
| 供应商 | `a` 新增、`e` 编辑、`c` 复制、`d` 删除、`i` 导入本机配置；`Enter` 切换 Codex 供应商或启动 Antigravity |
| MCP | `a` 新增、`Enter` 编辑、空格切换当前应用启用状态、`d` 删除、`i` 导入本机配置 |
| 提示词 | `a` 新增、`Enter` 编辑 Markdown、空格启用 / 停用、`d` 删除、`i` 导入本机提示词 |
| 技能 | `Enter` 查看 SKILL.md、空格启用 / 停用、`f` 发现、`g` 仓库、`a` ZIP 安装、`s` 同步、`u` 更新、`d` 卸载 |
| 技能发现 | 从启用的 GitHub 仓库发现技能、搜索、`Enter` 安装到当前应用 |
| 技能仓库 | 新增 / 编辑仓库及分支、开关发现、删除仓库 |
| 代理 | 查看 CLI / 桌面端端口状态；`s` 启动 CLI 后台代理、`x` 停止并分离客户端 |
| 用量与日志 | 当前应用的数据库用量汇总、请求日志；`,` / `.` 翻页，每页 50 条，`Enter` 查看详情 |
| 配置与备份 | 配置位置、`b` 创建 SQLite 一致性快照备份 |
| CLI 设置 | 代理用量记录、后台日志开关；空格切换，`Ctrl+S` 保存 |

删除、切换供应商、启停代理、安装 / 更新远程技能等操作会显示具体对象并要求确认。耗时操作在后台执行，显示进度提示；完成前暂停其他操作，仍可打开帮助。

## 编辑与保存

选择字段后按 `Enter` 编辑。单行按 `Enter`、多行按 `Ctrl+S` 应用到草稿；返回字段列表后再按 `Ctrl+S` 保存整个项目。`Esc` 取消，未保存的修改需确认丢弃。编辑支持方向键、Home/End、PageUp/PageDown、终端粘贴和 `Ctrl+U` 清空。

API Key 默认隐藏，`F2` 显示 / 隐藏。JSON、TOML 和 MCP 连接配置可能包含凭据，只有主动打开这些字段时才显示正文。格式错误时保留编辑内容；`F4` 查看错误详情。

供应商保留元数据、注释及核心保存规则，Codex 另有 `config.toml` 和代理推理参数 JSON 编辑入口。TOML 的全局设置变更会影响其他供应商，已运行的 Codex 需重新启动。新增第一家供应商可能由核心规则设为当前供应商。Antigravity 卡片在下次启动时使用新值；启动时暂时恢复普通终端，子进程结束后返回 TUI。

MCP 新增默认停用；JSON 支持 stdio 的 `command` / `args` / `env` 和 HTTP/SSE 的 `type` / `url` / `headers`。空格只切换当前应用，编辑保留其他应用开关，删除会从所有启用的应用移除。

提示词新增默认停用，启用后同步到该应用的提示词文件。已启用的模板需先停用才能删除。供应商、MCP 和提示词编辑会检查外部修改冲突；冲突时保留草稿，取消后刷新、重新打开并合并。

技能安装 / 更新 / 同步 / 卸载均调用核心服务，遵守目录冲突保护与本地修改备份规则。移除仓库不会卸载已经安装的技能。

## CLI 代理设置

CLI 设置只修改用户改动的字段，保留 `cli.json` 中其他字段。损坏的文件会报错，修复后按 `r` 重读。

两个开关仅影响 CLI 自己的后台代理，已运行的代理需要重启：

```bash
cc-switch-cli --app codex proxy disable
cc-switch-cli --app codex proxy enable
```

TUI 的代理页也可执行这两个操作。它不会停止桌面端创建的代理进程。Antigravity 不走 CLI 代理。

## 与参考项目的范围差异

当前覆盖上述主要管理模块。参考项目中的会话历史 / 回放、云同步设置、模型定价编辑、托管登录管理，以及它独有的其他应用页面尚未迁入。用量页读取已有数据库记录，不扫描客户端会话文件；配置页提供备份创建，不提供恢复或 SQL 导入。

输入或输出被重定向时，`tui` 会明确报错并退出。
