# 1.2 安装与升级

## 下载渠道

独立版从 **[Lemon00/cc-switch Releases](https://github.com/Lemon00/cc-switch/releases)** 下载。版本从 1.0.0 开始，实际可用文件以发布页为准。上游官网、Homebrew 和 AUR 中的同名包不是本独立版的发布渠道。

当前仓库工作流提供以下产物：

| 系统        | 文件                                    | 用法                                  |
| ----------- | --------------------------------------- | ------------------------------------- |
| Windows x64 | `CC-Switch-v1.0.0-Windows.msi`          | 按安装向导安装                        |
| Windows x64 | `CC-Switch-v1.0.0-Windows-Portable.zip` | 解压后运行其中的程序                  |
| Linux x64   | `CC-Switch-v1.0.0-Linux-x86_64.deb`     | Debian / Ubuntu 安装包                |
| Linux x64   | `CC-Switch-v1.0.0-Ubuntu-x86_64.tar.gz` | 解压运行 GUI，需要系统运行库          |
| Linux x64   | `cc-switch-cli`                         | 独立 CLI；赋予执行权限后运行 `--help` |

Windows 需要 WebView2。Linux GUI 需要 WebKitGTK 4.1、GTK 3 等运行库；压缩包不包含这些系统依赖。macOS、ARM64、RPM、AppImage 不在当前发布矩阵中，需要按[贡献指南](../../../../CONTRIBUTING.md)自行构建。源码的平台支持不代表本仓库已发布对应安装包。

## Windows

运行 MSI 完成安装。安装向导可选择是否创建桌面快捷方式；便携版解压后直接运行。

静默安装且不创建桌面快捷方式：

```powershell
msiexec /i "CC-Switch-v1.0.0-Windows.msi" /qn CREATEDESKTOPSHORTCUT=0
```

## Linux

在 Debian / Ubuntu 上，下载后从文件所在目录安装：

```bash
sudo apt install ./CC-Switch-v1.0.0-Linux-x86_64.deb
```

GUI 压缩包需要手动解压并运行其中的 `cc-switch`。CLI 单独下载后运行：

```bash
chmod +x cc-switch-cli
./cc-switch-cli --help
```

自行生成 AppImage 后如要使用开机自启，应将文件放在固定位置，再启用自启。Flatpak 的本地打包方法见 [Flatpak 构建](../../../../flatpak/README.md)。

## 从旧版迁移到 1.0.0

1. 在旧版「设置 → 数据」导出配置，另行备份配置目录、Skills 文件及受管客户端的原生配置。
2. 退出旧版，手动下载安装独立版。旧版 4.x 不会把 1.0.0 识别为更高版本。
3. Windows 如果阻止安装较低版本，先卸载旧应用，保留配置目录，再安装独立版。
4. 启动后核对供应商、配置目录及路由状态。版本号重新开始不会清空数据或重置数据库 schema。

避免同时运行两个版本修改同一套配置。回退旧程序时应恢复升级前的备份，而不是让旧程序直接读取新版数据库。

## 可选：安装要管理的工具

打开侧栏的「应用」，按工具提供的安装、升级及卸载入口操作（支持 Claude Code、Codex、OpenCode、DeepSeek Harness、Antigravity CLI）。能执行哪些操作取决于工具和平台；部分工具通过 npm 安装，需要满足该工具的 Node.js 要求，失败时查看页面提供的终端输出。

CC Switch 的二进制安装包本身不依赖 Node.js。不要把运行受管工具的环境要求和 CC Switch 的环境要求混在一起。

## 更新与卸载

「设置 → 关于」可以检查本仓库更新。应用内安装依赖发布时生成的签名和更新清单；缺少签名产物或使用绿色压缩包时，请从本仓库手动下载。源码中的版本修改和发布说明不表示安装包已经发布。

Windows 通过系统「应用」卸载；Linux deb 使用 `sudo apt remove cc-switch`；绿色版退出后移除程序目录。卸载程序与删除用户数据是两件事，确认不再需要时再处理[配置目录](../5-faq/5.1-config-files.md)。
